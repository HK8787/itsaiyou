# 相談フォームをメールで受け取る設定

`/entry` のフォームに入力された内容を、**スプレッドシートに自動で溜めつつ、
メールでも通知する**ための設定です。

かかる時間は5分程度、費用は無料です。
やることは実質**コピペ2回**だけです。

---

## 全体像

```
相談者がフォームに入力
        ↓
Google Apps Script（受け皿）
        ↓
   ┌────┴────┐
スプレッドシート   通知メール
（一覧で溜まる）  （pageya.info@gmail.com）
```

LINEでの相談窓口はこれまでどおり残ります。フォームを使わずLINEから直接
相談したい人は、そのまま緑のボタンから来られます。

---

## 手順

### 1. スプレッドシートを新規作成

https://sheets.new を開くだけです。名前は「相談フォーム受信」など分かるものに。

### 2. Apps Script を開く

メニューの **拡張機能 → Apps Script** をクリック。
新しいタブでエディタが開きます。

### 3. スクリプトを貼り付ける【コピペ1回目】

エディタに最初から入っている

```javascript
function myFunction() {
}
```

を **全部消して**、`docs/marketing/gas-form-receiver.gs` の中身を丸ごと貼り付け。

貼ったら保存（Ctrl+S または ⌘+S）。

### 4. 動作テスト（任意だがおすすめ）

エディタ上部の関数選択で **`testRun`** を選び、**実行** を押します。

初回は権限の確認が出ます。

- 「このアプリは Google で確認されていません」→ **詳細** → **（安全ではないページ）に移動**
- 自分で書いたスクリプトなので問題ありません。許可してください

成功すると、スプレッドシートにテスト行が1件増え、
`pageya.info@gmail.com` に通知メールが届きます。
**ここでメールが届けば、設定はほぼ完了です。**

### 5. ウェブアプリとしてデプロイ

エディタ右上の **デプロイ → 新しいデプロイ**。

| 項目 | 設定値 |
| --- | --- |
| 種類の選択（歯車） | **ウェブアプリ** |
| 次のユーザーとして実行 | **自分** |
| アクセスできるユーザー | **全員** ←ここ重要 |

「アクセスできるユーザー：全員」にしないと、サイトからの送信が届きません。

デプロイを押すと **ウェブアプリのURL** が出ます。

```
https://script.google.com/macros/s/AKfycb.........../exec
```

### 6. URLを渡す【コピペ2回目】

この `/exec` で終わるURLをコピーして送ってください。
サイト側への組み込みはこちらで行います。

## 補足

### スクリプトを直した場合

Apps Script を編集したら、**デプロイ → デプロイを管理 → 編集（鉛筆）→
バージョン「新バージョン」→ デプロイ** で反映してください。
新規デプロイするとURLが変わってしまうので注意。

### 通知メールの上限

無料のGmailアカウントから送れるのは1日100通までです。
相談が1日100件来るようになったら、うれしい悲鳴として別途考えましょう。

### 届かないとき

1. `testRun` でメールが届くか（届かない→権限承認が未完了）
2. デプロイの「アクセスできるユーザー」が **全員** になっているか
3. URLが `/exec` で終わっているか（`/dev` は本人しか使えません）

---

## プライバシーポリシーについて

この設定を入れると、フォームの入力内容が**Googleのサーバーと運営者のメールに
保存される**ことになります。

「入力内容はサーバーに保存しません」という従来の記載は事実と違ってしまうため、
サイトの記載はすでに実態に合わせて修正済みです（`/privacy`、`/entry`）。
