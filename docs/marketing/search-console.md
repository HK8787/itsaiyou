# Google Search Console の登録

サイトをGoogleにインデックスさせるための手続きです。**最優先。**

いま「ゼロイチIT」で検索しても、出てくるのはGitHubのリポジトリとPRページだけで、
サイト本体（`https://hk8787.github.io/itsaiyou/`）は出てきません。
公開しただけではGoogleは見つけてくれないので、こちらから申告します。

所要時間は**15分**。難しいところはありません。

---

## 先に、期待値の話

登録してもすぐ上位に出るわけではありません。順番はこうです。

| | 内容 | 目安 |
|---|---|---|
| 1 | 所有権の確認 | 即日 |
| 2 | インデックス登録（Googleのデータベースに載る） | 数日〜2週間 |
| 3 | 「ゼロイチIT」で自分のサイトが出る | 2週間〜1ヶ月 |
| 4 | 「未経験 IT 転職」などの一般語で出る | 半年〜 |

**狙うのは3までです。** 4は新規ドメインでは現実的ではありません。
知恵袋とnoteで流入を作りつつ、「ゼロイチIT」で検索した人が
ちゃんとサイトに辿り着ける状態を作るのが目的です。

指名検索で自分のサイトが出ないのは、知恵袋やXで屋号を見た人が
検索しても何も出てこないということなので、そこだけは潰しておきます。

---

## 手順

### ステップ1：プロパティを追加する

1. <https://search.google.com/search-console> を開く
2. Googleアカウントでログイン（`pageya.info@gmail.com` でよい）
3. 左上の「プロパティを追加」

**「ドメイン」と「URLプレフィックス」の2択が出ます。右の「URLプレフィックス」を選んでください。**

左の「ドメイン」はDNSの設定が必要で、`github.io` はGoogleのドメインではないので設定できません。

URLは末尾のスラッシュまで含めて、これをそのまま貼ります。

```
https://hk8787.github.io/itsaiyou/
```

> **補足**：`github.io` は Public Suffix List に載っているので、
> Googleは `hk8787.github.io` を独立したサイトとして扱います。
> 他人のGitHub Pagesと評価が混ざることはありません。

### ステップ2：所有権を確認する

確認方法がいくつか出てきます。**「HTMLタグ」**を選んでください。

こういうタグが表示されます。

```html
<meta name="google-site-verification" content="ここが長い英数字の文字列" />
```

**必要なのは `content="..."` の中身だけ**です。タグ全体ではありません。
この文字列をコピーして、次のどちらかで設定します。

#### 方法A：GitHubの設定画面で入れる（コード変更なし・推奨）

1. リポジトリの **Settings** → 左メニューの **Secrets and variables** → **Actions**
2. 上のタブで **Variables** を選ぶ（Secretsではありません）
3. **New repository variable**
4. Name に `GOOGLE_SITE_VERIFICATION`、Value にコピーした文字列
5. **Add variable**

#### 方法B：コードに直接書く

`src/data/site.ts` の `googleSiteVerification` の `""` の中に貼ってコミットする。

> このトークンは秘匿情報ではありません。どのみちHTMLに出力されて誰でも見られます。
> 所有権の証明にしか使えず、これだけで何かできるものではないので、
> Secretsではなく Variables で構いません。

### ステップ3：デプロイする

方法Aの場合、Variableを登録しただけではサイトに反映されません。
ビルドし直す必要があります。

- リポジトリの **Actions** タブ → 左の **Deploy to GitHub Pages**
- 右の **Run workflow** → ブランチは `main` → 緑の **Run workflow**

2〜3分で終わります。緑のチェックが付いたら完了です。

方法Bの場合は、mainにマージした時点で自動で走ります。

反映されたかどうかは、`https://hk8787.github.io/itsaiyou/` を開いて
ページのソースを表示し、`google-site-verification` を検索すれば分かります。

### ステップ4：確認ボタンを押す

Search Consoleの画面に戻って**「確認」**を押します。
「所有権を証明しました」と出れば完了です。

出ない場合は、ステップ3のデプロイが終わっていないことがほとんどです。
数分おいてもう一度押してください。

### ステップ5：サイトマップを送信する

ここまで来たら、どんなページがあるかをGoogleに渡します。

1. 左メニューの **サイトマップ**
2. 「新しいサイトマップの追加」の入力欄に `sitemap.xml` と入力
   （前半のURLは自動で入っています）
3. **送信**

「成功しました」と出れば終わりです。
このサイトマップはビルドのたびに自動生成されるので、
ページを足しても手作業は要りません。

### ステップ6：トップページのインデックス登録をリクエストする

待っていてもいずれ拾われますが、こちらから頼んだほうが早いです。

1. 画面上部の検索窓（「URLを検査」）に `https://hk8787.github.io/itsaiyou/` を貼る
2. 「URLがGoogleに登録されていません」と出る
3. **「インデックス登録をリクエスト」**をクリック

同じことを、主要ページにもやっておきます。

```
https://hk8787.github.io/itsaiyou/
https://hk8787.github.io/itsaiyou/about/
https://hk8787.github.io/itsaiyou/guide/
https://hk8787.github.io/itsaiyou/courses/
```

**1日あたりのリクエスト数に上限があります**（十数件程度）。
全ページやる必要はありません。上の4つで十分です。

## 登録後に見るところ

毎日見る必要はありません。**週1回で十分**です。

| メニュー | 見るもの |
|---|---|
| **ページ** | インデックスされた件数。ここが0から増えていけば正常 |
| **検索結果** | どんな検索語で表示されたか。**ここが一番おもしろい** |
| **サイトマップ** | ステータスが「成功しました」のままか |

とくに**「検索結果」→「クエリ」**は見てください。
自分が想定していなかった言葉で表示されていることがよくあります。
そこに需要があるということなので、記事や知恵袋の回答のネタになります。

## よくあるつまずき

**「確認」を押してもエラーになる**
→ デプロイが終わっていません。Actionsタブで緑のチェックを確認してから押してください。

**タグ全体を Variable に貼ってしまった**
→ `content="..."` の中身だけです。`<meta ...>` は要りません。

**「ドメイン」プロパティで登録しようとした**
→ `github.io` のDNSは設定できないので、URLプレフィックスを使ってください。

**1週間経ってもインデックスされない**
→ 新規サイトでは普通にあります。被リンクが0だと時間がかかります。
　 知恵袋のプロフィールとnoteからリンクが張られると速くなるので、
　 そちらを先に進めてください。

## 補足：robots.txt について

このサイトは `https://hk8787.github.io/itsaiyou/robots.txt` を出力していますが、
**クローラはサブディレクトリの robots.txt を読みません。**
robots.txt はドメイン直下（`https://hk8787.github.io/robots.txt`）のものだけが有効です。

ただし、これは問題になりません。

- robots.txt が無い ＝ 全許可、が既定の扱いです
- サイトマップはSearch Consoleから直接送信するので、
  robots.txt の `Sitemap:` 行に頼る必要がありません

独自ドメインに移す場合は、ルート配信になるので自動的に解決します。
そのときは `src/data/site.ts` の `url` と、
`.github/workflows/deploy.yml` の `BASE_PATH` を書き換えてください。
**あわせて Search Console にも新しいプロパティを追加し直す必要があります**
（URLが変わると別サイト扱いになるため）。
