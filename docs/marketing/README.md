# 集客のやり方

サイトを公開しただけでは誰も来ません。ここに、何をどこで発信するかをまとめます。

---

## 1. 大前提：出せる広告と、出せない広告

**出せません**

- Indeed・求人ボックス・スタンバイ等への求人出稿
  → 求人広告を出せるのは求人企業本人か、許可を持った職業紹介事業者だけです。
    運営者はどちらでもないので、自分名義で「エンジニア募集」は出せません。

**出せます**

- 「IT転職の無料キャリア相談やってます」という **相談窓口としての告知**
- 自分の体験談・業界の解説などの **コンテンツ発信**

サイトもこの前提で「求人広告サイト」ではなく「相談窓口＋求人はモデルケース提示」という
構成にしてあります。発信も同じ線を守ってください。

---

## 2. 最大の武器は、自分の実体験

運営者ご自身が **未経験からIT業界に入って実務を続けている** という事実。
これが他の転職アカウントに対する決定的な差です。

一般論を語るアカウントは山ほどありますが、
「自分もそっち側だった人」の言葉は刺さり方がまったく違います。

発信の軸はこれ一本で決まりです。

> 未経験からITに入って、今も現場にいる人間が、当時の自分に向けて書く

ターゲットは **過去の自分**。これを外さないでください。

---

## 3. チャネルは1つに絞る

同時に複数やると全部が中途半端になります。まず1つ、3ヶ月やり切る。

| チャネル | 向き | コスト | 立ち上がり |
| --- | --- | --- | --- |
| **X（旧Twitter）** | ◎ 最推奨 | 0円 | 1〜3ヶ月 |
| TikTok | ○ | 0円 | 2週間〜（バズれば早い） |
| Instagram | △ | 0円 | 3ヶ月〜 |
| ブログ/SEO | △ | ドメイン代 | 6ヶ月〜 |
| Meta広告 | ○ | 月3万円〜 | 即日 |

### Xを推す理由

- 匿名で始められる（本名・顔出し不要）
- 「未経験 IT 転職」で検索している人に、リプライで直接届く
- テキストなので、隙間時間で回せる
- 転職系は相性がいい

### TikTokも併用するなら

Xで書いた内容をそのまま読み上げるだけで動画になります。
ただし顔出しの心理的ハードルがあるので、無理なら後回しで構いません。

---

## 4. 最初の90日でやること

### Week 1〜2：土台

- [ ] Xアカウント開設（プロフィールに相談サイトのURL）
- [ ] LINE公式アカウント開設 → 友だち追加URLを `site.ts` に反映
- [ ] サイトをデプロイ（docs/DEPLOY.md）
- [ ] 固定ポスト（ピン留め）を1本書く ＝ 自己紹介＋何ができるか

### Week 3〜12：毎日1〜3投稿

- `x-posts.md` の型に沿って投稿
- 「未経験 IT 転職」「IT 転職 不安」等で検索し、悩んでいる投稿にリプライ
  （売り込まない。役に立つ情報だけ置いてくる）
- 週1本、サイトの未経験ガイドに新記事を足す

### 目標の目安

| 指標 | 3ヶ月後の目安 |
| --- | --- |
| Xフォロワー | 300〜1,000 |
| LINE友だち追加 | 5〜20件 |
| 面談まで進む人 | 2〜5件 |
| 内定 | 0〜2件 |

最初の1件が出るまでが一番きついところです。ここで辞める人が大半なので、
逆に言えば続けるだけで残れます。

---

## 5. 言ってはいけないこと

発信でこれをやると、景品表示法・職業安定法に触れる可能性があります。

**断定・誇大表現はNG**

- ✕「絶対に転職できます」「必ず年収◯◯万円になれます」
- ○「〜のケースが多いです」「〜を狙える可能性があります」

**実績の捏造はNG**

- ✕ 支援実績がないのに「支援実績100名」と書く
- ○ 実績が出てから、事実だけ書く

**紹介料の関係は隠さない**

ステルスマーケティング規制（景表法）の対象になります。
サイトの `/about` には既に明記してあるので、SNSでも聞かれたら正直に答えてください。
むしろ先に開示したほうが信用されます。

**求職者から金銭を受け取らない**

職業安定法で原則禁止です。「有料のキャリア相談」「情報商材」に寄せた瞬間に別の話になります。
このモデルは求職者無料が前提です。

## 6. ファイル一覧

- `x-posts.md` … X投稿の型とすぐ使える下書き
- `line-templates.md` … 友だち追加後〜取次ぎまでのLINE返信テンプレ
- `candidates.csv` … 候補者管理シートの**雛形**

### ⚠️ 候補者の個人情報について

**このリポジトリは公開です。** GitHub上の全ファイルを誰でも閲覧できます。

`candidates.csv` は列の設計を示す雛形であり、**実データを書き込まないでください。**
氏名・年齢・学歴・在職状況は個人情報です。公開リポジトリに載せた時点で
取り返しがつきません（コミット履歴に残るため、後から消しても復元できます）。

実際の管理には、次のどちらかを使ってください。

1. **Googleスプレッドシート**（推奨）
   `candidates.csv` をそのままインポートすれば、列がそのまま使えます。
   共有設定は「制限付き（自分のみ）」にすること。
2. **ローカルのファイル**
   `candidates-real.csv` のような名前で保存してください。
   この名前は `.gitignore` に登録済みなので、誤ってコミットされません。

あわせて、サイトのプライバシーポリシーに書いた内容と、実際の扱いが
食い違わないようにしてください（`src/app/privacy/page.tsx`）。
