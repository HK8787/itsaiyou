# LINE返信テンプレート

友だち追加されてから、提携先へお繋ぎするまでの流れ。
そのままコピペせず、相手の状況に合わせて崩してください。
**テンプレ感が出た瞬間に信用を失います。**

---

## 原則

1. **即レス**。24時間以内、できれば数時間以内。遅いと熱が冷めます
2. **13項目は「質問」ではなく「テンプレ」として渡す**。
   順番に聞くと13往復になり、途中で切れます。
   コピペできる雛形を1回で渡し、**必ず逃げ道（埋めなくてよい・質問だけでもよい）を添える**
3. **売り込まない**。「転職しなくていいです」と最初に言うほうが結果的に進みます
4. **絵文字は控えめに**。多用すると業者感が出ます

---

## 1. 友だち追加された直後（あいさつメッセージに設定）

LINE公式アカウントの管理画面 →「あいさつメッセージ」に設定します。
**吹き出しは3つに分けてください。** 1つにまとめると、開いた瞬間に
壁のような文章が出てきて、読まれる前に閉じられます。

吹き出しは最大5つ、1つあたり500文字までです。下の3つはいずれも収まります。

### 吹き出し1：名乗りと、身構えを解く

```
はじめまして、ゼロイチITです！
登録ありがとうございます。

相談は何度でも無料、営業の連絡もしません。
転職を決めなくても全然OKです。

私自身、調理の仕事から未経験でITに入って今4年目です。
何も分からないところから始めたので、
初歩的なことでも遠慮なく聞いてください。
```

### 吹き出し2：13項目

```
さっそくですが、下をコピーして埋めて送ってください！

ここが揃えば、その日のうちに
「どの求人なら通りそうか」までお伝えできます。

ーーーーーーーーーー
①お名前
②年齢
③最終学歴 ※不問の求人が中心です
④働きたい都道府県
⑤いつから働きたいか
⑥在職中／離職中
⑦直近の雇用形態
（正社員／契約／派遣／バイト／業務委託／経験なし）
⑧直近の在籍年数
⑨転職回数 ※多くても大丈夫です
⑩お住まいの都道府県
⑪転職したい理由（一言でOK）
⑫希望の職種
（インフラ／WEB開発／Salesforce／ヘルプデスク／未定）
⑬その職種は絶対条件？
（絶対／条件次第／こだわらない）
ーーーーーーーーーー
```

### 吹き出し3：逃げ道を用意する

```
空欄があっても大丈夫です！
分かるところだけで進められます。

先に質問だけしたい方は、埋めずに
聞きたいことをそのまま送ってください。

24時間以内に返します（土日祝も見ています）
```

### 設計の意図

**「質問」ではなく「テンプレ」として渡す。**
13個を順に聞くと13往復かかって途中で切れます。雛形なら1往復で終わります。

**③と⑨に注釈を付けている理由。**
最終学歴と転職回数は、この層が一番触れられたくない2項目です。
人と一言も話していない段階で聞かれると手が止まるので、
その場でフォローを読めるよう、項目のすぐ横に置いています。
**この2つの注釈は消さないでください。**

**⑦⑫⑬に選択肢を併記する理由。**
自由記述だと手が止まります。選ぶだけなら止まりません。

**吹き出し3が安全弁です。**
重いと感じた人の離脱をここで受け止めます。有無で初回返信率が変わります。

**⑭の連絡先（メールアドレス）は聞きません。**
フォームの14番目は返信先を確保するための項目で、
LINEで繋がっている時点で不要です。

**絵文字は足しても1〜2個まで。**
多いと業者アカウントに見えます。「！」で十分テンションは出ます。

### 送られてきたら

内容を読んで、**まず1つコメントしてから**次に進んでください。
いきなり「ありがとうございます、では提携先へ」だと自動処理に見えます。

⑪の転職理由に必ず何か書いてあるので、そこに触れるのが自然です。
返し方は下の「2. 最初の返信が来たら」を参考に。

## 2. 最初の返信が来たら

相手が何か送ってきたら、**まず受け止めてから1つだけ質問**します。

### パターンA：「情報収集だけ」と言われた

```
ありがとうございます。情報収集の段階でまったく問題ないです。

むしろ、その段階で調べている人のほうが
入社後に「思ってたのと違った」となりにくいです。

もしよければ、いま気になっていることを教えてください。
・そもそもどんな職種があるのか
・自分の経歴でも入れるのか
・給料や働き方がどうなるのか

このあたりでしたら、だいたいお答えできます。
```

### パターンB：「転職したい」と言われた

```
ありがとうございます。

進め方としては、先に方向性をすり合わせてから
求人を見たほうが確実なので、いくつか状況を伺えればと思います。

まず、いちばん大きいところだけ。

いつ頃までに働き始めたいですか？
（すぐにでも／3〜6ヶ月後／半年以上先でもいい）
```

### パターンC：不安を打ち明けられた（学歴・経歴・年齢など）

ここが一番大事な場面です。**否定も過剰な励ましもしない。**

```
正直に書いていただいてありがとうございます。

結論から言うと、それが理由で無理ということはないです。
ただ、面接でどう説明するかは考えておく必要があります。
逆に言えば、そこさえ準備すればカバーできる範囲です。

差し支えなければ、もう少し詳しく教えてもらえますか。
一緒に整理します。
```

## 4. 13項目がまだ埋まっていない場合

あいさつメッセージで渡したテンプレに答えず、
質問から入った人向けです。**方向性が固まってから聞いてください。**

```
ありがとうございます。では次のステップに進みます。

この先は、実際に求人を紹介できる提携先の担当者に
お繋ぎする形になります。

その前に、先方が確認する項目があります。
最初にお送りしたテンプレートがそれなので、
お手すきのときに埋めて送ってください。

打ち込むのが面倒でしたら、こちらのフォームでも同じ内容が入力できます。
入力後に出てくるテキストを、そのまま貼り付けていただく形でも大丈夫です。

https://hk8787.github.io/itsaiyou/entry/
```

### フォームが面倒がられたら

```
フォームが面倒でしたら、ここに直接書いていただいても大丈夫です。

1. 氏名
2. 年齢
3. 最終学歴
4. 入社希望の都道府県
5. 入社希望月
6. 在職中か離職中か
7. 直近の雇用形態
8. 直近企業の在籍年数
9. 転職回数
10. 現在お住まいの都道府県
11. 転職理由（一言で大丈夫です）
12. 希望の職種
13. その職種は絶対条件ですか

分からない項目は飛ばしてください。
```

## 5. 提携先へお繋ぎする

**ここで、自分の立場を必ず明示します。** 後出しにしないこと。

```
ありがとうございます。内容を確認しました。

ここから先は、厚生労働大臣の許可を受けた提携先の
職業紹介事業者にお繋ぎします。
求人の紹介・書類の添削・面接の調整は、そちらが担当します。

なお、私は職業紹介の許可を持っていないため、
お繋ぎするところまでが私の役割です。
採用が決まった場合、提携先から私に紹介料が支払われる
仕組みになっています。先にお伝えしておきます。

もちろん、◯◯さんの費用負担は一切ありません。

このまま進めて大丈夫でしょうか。
```

## 6. 面接前のフォロー

繋いで終わりにしないこと。ここで差がつきます。

```
面接お疲れさまです。日程決まりましたか。

未経験枠でほぼ必ず聞かれるのが、この3つです。

・なぜIT業界なのか
・なぜその職種なのか
・入社後どう勉強していくつもりか

答え方をまとめてあるので、面接前に一度読んでおいてください。
https://hk8787.github.io/itsaiyou/guide/why-it/

もしよければ、考えた答えをここに送ってください。
伝わりにくいところがあればお返しします。
```

## 7. 入社後（1ヶ月・3ヶ月・半年）

継続報酬が発生するルートでは特に重要。
純粋に、辞められたら誰も得をしません。

```
入社から1ヶ月ですね。いかがですか。

最初の1〜3ヶ月がいちばんしんどい時期です。
覚えることが多くて、周りが何を話しているかも分からない。
ほぼ全員が同じところで一度つまずきます。

何かあれば、ここにそのまま書いてください。
愚痴でも大丈夫です。
```

## やってはいけないこと

| NG | 理由 |
| --- | --- |
| 初手で13項目を送る | 高確率でブロックされます |
| 「絶対に転職できます」と言う | 景品表示法に触れる可能性 |
| 紹介料の関係を隠す | ステマ規制の対象。信用も失います |
| 求職者からお金を取る | 職業安定法で原則禁止 |
| 合わない人を無理に進める | 早期退職につながり、双方が損をします |
| 返信を何日も放置する | 熱が冷めて終わります |
