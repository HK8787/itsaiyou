# LINE返信テンプレート

友だち追加されてから、提携先へお繋ぎするまでの流れ。
そのままコピペせず、相手の状況に合わせて崩してください。
**テンプレ感が出た瞬間に信用を失います。**

---

## 原則

1. **即レス**。24時間以内、できれば数時間以内。遅いと熱が冷めます
2. **13項目は「質問」ではなく「テンプレ」として渡す**。
   順番に聞くと13往復になり、途中で切れます。
   コピペできる雛形を1回で渡し、**必ず逃げ道（埋めなくてよい・質問だけでもよい）を添える**
3. **売り込まない**。「転職しなくていいです」と最初に言うほうが結果的に進みます
4. **絵文字は控えめに**。多用すると業者感が出ます

---

## 1. 友だち追加された直後（あいさつメッセージに設定）

LINE公式アカウントの管理画面 →「あいさつメッセージ」に設定します。
**吹き出しは3つに分けてください。** 1つにまとめると、開いた瞬間に
壁のような文章が出てきて、読まれる前に閉じられます。

吹き出しは最大5つ、1つあたり500文字までです。下の3つはいずれも収まります。

### 吹き出し1：名乗りと、身構えを解く

```
はじめまして、ゼロイチITです！
登録ありがとうございます。

相談は何度でも無料、営業の連絡もしません。
転職を決めなくても全然OKです。

私自身、調理の仕事から未経験でITに入って今4年目です。
何も分からないところから始めたので、
初歩的なことでも遠慮なく聞いてください。
```

### 吹き出し2：13項目

```
さっそくですが、下をコピーして埋めて送ってください！

ここが揃えば、その日のうちに
「どの求人なら通りそうか」までお伝えできます。

ーーーーーーーーーー
①お名前
②年齢
③最終学歴 ※不問の求人が中心です
④働きたい都道府県
⑤いつから働きたいか
⑥在職中／離職中
⑦直近の雇用形態
（正社員／契約／派遣／バイト／業務委託／経験なし）
⑧直近の在籍年数
⑨転職回数 ※多くても大丈夫です
⑩お住まいの都道府県
⑪転職したい理由（一言でOK）
⑫希望の職種
（インフラ／WEB開発／Salesforce／ヘルプデスク／未定）
⑬その職種は絶対条件？
（絶対／条件次第／こだわらない）
ーーーーーーーーーー
```

### 吹き出し3：逃げ道を用意する

```
空欄があっても大丈夫です！
分かるところだけで進められます。

先に質問だけしたい方は、埋めずに
聞きたいことをそのまま送ってください。

24時間以内に返します（土日祝も見ています）
```

### 設計の意図

**「質問」ではなく「テンプレ」として渡す。**
13個を順に聞くと13往復かかって途中で切れます。雛形なら1往復で終わります。

**③と⑨に注釈を付けている理由。**
最終学歴と転職回数は、この層が一番触れられたくない2項目です。
人と一言も話していない段階で聞かれると手が止まるので、
その場でフォローを読めるよう、項目のすぐ横に置いています。
**この2つの注釈は消さないでください。**

**⑦⑫⑬に選択肢を併記する理由。**
自由記述だと手が止まります。選ぶだけなら止まりません。

**吹き出し3が安全弁です。**
重いと感じた人の離脱をここで受け止めます。有無で初回返信率が変わります。

**⑭の連絡先（メールアドレス）は聞きません。**
フォームの14番目は返信先を確保するための項目で、
LINEで繋がっている時点で不要です。

**絵文字は足しても1〜2個まで。**
多いと業者アカウントに見えます。「！」で十分テンションは出ます。

### 送られてきたら

内容を読んで、**まず1つコメントしてから**次に進んでください。
いきなり「ありがとうございます、では提携先へ」だと自動処理に見えます。

⑪の転職理由に必ず何か書いてあるので、そこに触れるのが自然です。
返し方は下の「2. 最初の返信が来たら」を参考に。

## 2. 最初の返信が来たら

相手が何か送ってきたら、**まず受け止めてから1つだけ質問**します。

### パターンA：「情報収集だけ」と言われた

```
ありがとうございます。情報収集の段階でまったく問題ないです。

むしろ、その段階で調べている人のほうが
入社後に「思ってたのと違った」となりにくいです。

もしよければ、いま気になっていることを教えてください。
・そもそもどんな職種があるのか
・自分の経歴でも入れるのか
・給料や働き方がどうなるのか

このあたりでしたら、だいたいお答えできます。
```

### パターンB：「転職したい」と言われた

```
ありがとうございます。

進め方としては、先に方向性をすり合わせてから
求人を見たほうが確実なので、いくつか状況を伺えればと思います。

まず、いちばん大きいところだけ。

いつ頃までに働き始めたいですか？
（すぐにでも／3〜6ヶ月後／半年以上先でもいい）
```

### パターンC：不安を打ち明けられた（学歴・経歴・年齢など）

ここが一番大事な場面です。**否定も過剰な励ましもしない。**

```
正直に書いていただいてありがとうございます。

結論から言うと、それが理由で無理ということはないです。
ただ、面接でどう説明するかは考えておく必要があります。
逆に言えば、そこさえ準備すればカバーできる範囲です。

差し支えなければ、もう少し詳しく教えてもらえますか。
一緒に整理します。
```

3ルートのどれが合いそうか見えた段階で、サイトに誘導します。

```
お話を伺った感じだと、◯◯のルートが現実的だと思います。

理由は、
・◯◯（相手の状況に紐づけて具体的に）
・◯◯

詳しくはこちらにまとめてあるので、
一度目を通してみてください。
https://hk8787.github.io/itsaiyou/courses/

読んだうえで「やっぱり違うかも」と思ったら、
遠慮なく言ってください。そこから考え直せばいいので。
```

### IT以外のほうが合いそうな場合

提携先は職種を問わず正社員求人を扱っているので、ここで切らずにそのまま繋げます。
ITに寄せようとしないこと。合わない人をITに入れると、すぐ辞めて誰も得をしません。

```
お話を伺った感じだと、正直ITより◯◯のほうが合っていると思います。

理由は、
・◯◯（相手の状況に紐づけて具体的に）
・◯◯

お繋ぎしている提携先はITに限らず正社員の求人を扱っているので、
◯◯の方向でも探してもらえます。
ITと並べて比べることもできるので、迷っていても大丈夫です。
```

## 4. 13項目がまだ埋まっていない場合

あいさつメッセージで渡したテンプレに答えず、
質問から入った人向けです。**方向性が固まってから聞いてください。**

```
ありがとうございます。では次のステップに進みます。

この先は、実際に求人を紹介できる提携先の担当者に
お繋ぎする形になります。

その前に、先方が確認する項目があります。
最初にお送りしたテンプレートがそれなので、
お手すきのときに埋めて送ってください。

打ち込むのが面倒でしたら、こちらのフォームでも同じ内容が入力できます。
入力後に出てくるテキストを、そのまま貼り付けていただく形でも大丈夫です。

https://hk8787.github.io/itsaiyou/entry/
```

## 5. 提携先へお繋ぎする

### 取次ぎの流れ（提携先と合意済み）

LINE公式アカウントは、グループを作ったり人を招待したりができません。
そのため、グループは提携先側が作り、こちらは参加方法を伝える役になります。

| ステップ | 誰が | やること |
| --- | --- | --- |
| 1 | 候補者 | 13項目を記入して、公式LINEに送る |
| 2 | こちら | 提携先とのグループトークに13項目を共有し、支援できるか確認してもらう |
| 3 | 提携先 | 支援できる場合、候補者用のグループトークを作り、参加用のIDを発行する |
| 3 | こちら | 公式LINEから、そのIDを候補者に伝える |
| 4 | 候補者 | グループに参加する。ここから提携先の支援が始まる |

**ステップ2の前に、必ず本人の了承を取ってください。**
13項目には氏名が入っています。提携先に渡すのは第三者への提供にあたるので、
了承なしに共有すると、プライバシーポリシー（「ご本人が希望された場合にのみ」）に反します。
下の5-1のメッセージで了承をもらってから共有すること。

紹介料や、こちらが職業紹介の許可を持っていないことは、**自分からは言いません。**
仕組みは `/about` に公開してあるので、聞かれたときに正直に答えれば足ります（5-1の下の文面）。
聞かれてごまかしたり、否定したりはしないこと。

本人が「エージェントさんを使いたい」と自分から言っている場合は、それを了承として扱って構いません。

**13項目を受け取ったら、相談はこちらで抱え込まないこと。**
求人選びや書類の相談は、提携先に渡すのが目的です。
「気になる求人があれば送ってください」のように、こちらへ相談を戻す一文は入れません。
支援可否を待ってもらう間のメッセージは、「エージェントさんから返事が来たら、すぐ連絡しますね」のように、
次の連絡を伝えるだけで締めてください。エージェントの良さを売り込む一文は要りません。

**例外：入社希望が3か月より先の場合。**
提携先のサポートは入社希望月の3か月前から始まります（4月入社なら1月から）。
それまでの期間は、方向性の整理や職務経歴書の準備をこちらで一緒に進め、関係を切らさないこと。
サポート開始の少し前に、本人の近況確認と、提携先への開始の連絡を忘れないようにしてください
（会話の中でリマインドを予約しておくと確実です）。

### 5-1. 13項目が届いたら（了承の確認）

```
ありがとうございます。内容を確認しました。

この先は、提携しているエージェントさんにお繋ぎする形になります。
正社員の求人に絞って、ITに限らず探してもらえます。
書類は応募する求人ごとに直してもらえますし、模擬面接もあります。
土日や平日の夜でも相談できるので、仕事終わりでも大丈夫です。
費用は一切かかりません。

進めてよければ、いただいた内容をエージェントさんに共有して、
支援できるかどうかを確認してもらいます。
結果が出たらこちらから連絡しますね。
このまま進めて大丈夫でしょうか。
```

#### 紹介料や立場について聞かれたら

```
はい、私自身は職業紹介の許可を持っていないので、
お繋ぎするところまでが私の役割です。
採用が決まった場合、エージェントさんから私に紹介料が支払われる仕組みです。
◯◯さんが費用を負担することは一切ありません。
```

### 5-2. 提携先のグループに共有する（ステップ2）

候補者から了承をもらったら、13項目をそのまま貼り付けます。
LINE上のやり取りから拾った補足（希望の方向、気にしている点など）があれば、
一言添えると提携先が判断しやすくなります。

```
【新規候補者】支援可否のご確認をお願いします

（13項目をそのまま貼り付け）

補足：◯◯（例：設備管理・ビルメン志望。データセンター常駐を希望）
```

### 5-3. 支援できると返事が来たら（ステップ3）

```
お待たせしました！
提携先から、◯◯さんの支援ができると返事がありました。

担当の方と直接やり取りするためのグループを作ってもらったので、
下のIDから参加してください。

（ID）

参加していただいたら、そこから担当の方が進めてくれます。
求人のことも書類のことも、担当の方に何でも相談してください。
```

参加後の相談は、担当の方に向けてもらいます。
6章以降のフォローは、面接前後に一言声をかける程度で十分です。

### 5-4. 支援が難しいと返事が来たら

隠さずに伝えます。理由が分かれば添えて、次にできることを一つ出してください。

```
お待たせしました。
提携先に確認したところ、今の条件だと
すぐにご紹介できる求人が見つからないとのことでした。

（理由が分かれば一言）

条件や時期が変われば状況も変わるので、
そのときはまた声をかけてください。
求人票の見方や書類のことなど、私で答えられることは引き続き答えます。
```

繋いで終わりにしないこと。ここで差がつきます。

```
面接お疲れさまです。日程決まりましたか。

未経験枠でほぼ必ず聞かれるのが、この3つです。

・なぜIT業界なのか
・なぜその職種なのか
・入社後どう勉強していくつもりか

答え方をまとめてあるので、面接前に一度読んでおいてください。
https://hk8787.github.io/itsaiyou/guide/why-it/

もしよければ、考えた答えをここに送ってください。
伝わりにくいところがあればお返しします。
```

## 7. 入社後（1ヶ月・3ヶ月・半年）

継続報酬が発生するルートでは特に重要。
純粋に、辞められたら誰も得をしません。

```
入社から1ヶ月ですね。いかがですか。

最初の1〜3ヶ月がいちばんしんどい時期です。
覚えることが多くて、周りが何を話しているかも分からない。
ほぼ全員が同じところで一度つまずきます。

何かあれば、ここにそのまま書いてください。
愚痴でも大丈夫です。
```

## やってはいけないこと

| NG | 理由 |
| --- | --- |
| 初手で13項目を送る | 高確率でブロックされます |
| 「絶対に転職できます」と言う | 景品表示法に触れる可能性 |
| 紹介料について聞かれて、ごまかす・否定する | 嘘になります。信用も失います（自分から毎回言う必要はありません） |
| 求職者からお金を取る | 職業安定法で原則禁止 |
| 合わない人を無理に進める | 早期退職につながり、双方が損をします |
| 返信を何日も放置する | 熱が冷めて終わります |
