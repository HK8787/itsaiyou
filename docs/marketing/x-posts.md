# X（旧Twitter）投稿の型と下書き

## 大前提

**【 】はご自身の実際の経歴に置き換えてください。**
事実でないことは一文字も書かないこと。作り話は必ずバレますし、
バレなくても、嘘の実体験を軸にしたアカウントは長く続きません。

書けるのは「自分が本当に体験したこと」と「調べて分かったこと」だけです。

---

## プロフィール（まずこれを整える）

```
未経験からITエンジニアになって【N】年目 ／ 前職は【業種】
「自分にIT業界は無理」と思ってた側の人間です
未経験転職の相談に無料で乗ってます（費用は一切かかりません）
→ 相談はこちら
```

固定ポスト（ピン留め）はこれ。

```
【前職】から未経験でIT業界に入って【N】年経ちました。

入る前はずっと「自分には無理」だと思ってました。
【学歴や経歴の事実】だったので、求人の「大卒以上」で
毎回止まってたし、パソコンもろくに触ってなかった。

でも入ってみたら、学歴の話は最初の一瞬だけでした。

同じところで止まってる人向けに、
当時の自分が知りたかったことをまとめています。
相談も無料で受けてます。営業はしません。

<サイトURL>
```

## 投稿の4分類

毎日1〜3本。この4つを混ぜて回します。

| 型 | 割合 | 目的 |
| --- | --- | --- |
| A. 体験談 | 40% | 信用をつくる。最強の武器 |
| B. 実用情報 | 30% | 保存・拡散される |
| C. 共感 | 20% | ターゲットに刺さる |
| D. 導線 | 10% | 相談につなげる |

CTAを毎回つけないこと。売り込み臭が出ると伸びなくなります。

---

## A. 体験談（40%）

埋めて使ってください。

```
未経験でIT業界に入った初日、
先輩の会話が本当に1ミリも分からなかった。

【実際に分からなかった単語を3つ】

メモ帳に書いて、家で調べる。
これを毎日やって、3ヶ月でようやく会話についていけた。

最初から分かってる人なんていません。
```

```
未経験入社して一番きつかったのは、
技術じゃなくて【実際にきつかったこと】でした。

想像してた「バリバリ作る仕事」には
しばらく辿り着きません。

でもここで腐らずに1〜2年続けた人が、
次のステージに行ってます。
```

```
転職して【N】年。
正直に書くと、1年目の年収は【上がった/下がった】。

【理由を一言】

ここを「数年の投資期間」と思えるかどうかが
分かれ目だと思う。
```

```
面接で「なぜIT業界なんですか」と聞かれて、
自分はこう答えました。

【実際に答えた内容】

用意していったから答えられただけです。
その場で考えて答えられる質問じゃないです。
```

```
IT業界に入って一番良かったのは、
【実際に良かったこと】。

学歴を聞かれたのは、面接の1回だけでした。
あとは何年やったかの話になります。
```

## B. 実用情報（30%）

```
未経験からITで、現実的に入れる職種。

・インフラエンジニア（求人が一番多い）
・ヘルプデスク（入口として一番ハードルが低い）
・テストエンジニア
・Salesforce（資格が市場価値に直結）

逆に、未経験からいきなりは厳しい職種。

・AI／機械学習
・セキュリティ
・ITコンサル
・ゲームプログラマ

諦めろという話ではなく、入口が違うだけです。
```

```
未経験の面接でほぼ100%聞かれる3つ。

1. なぜIT業界なのか
2. なぜその職種なのか
3. 入社後どう勉強していくつもりか

3番に「頑張ります」と答えると落ちます。
「平日1時間、休日3時間。半年でCCNA取ります」
みたいに、時間と目標をセットで言う。
```

```
相談される前に、これだけやっておくと話が早いです。

1. 無料の学習サイトを合計3時間触る
   （スキルより「苦痛じゃないか」の確認）
2. 月にいくらあれば生活が回るか計算する
3. 譲れない条件を3つだけ決める

これがあると、選択肢が1〜2個に絞れます。
```

```
「未経験歓迎」の求人でも、
これを言うと一気に落ちやすくなる。

「全然分からないので、色々教えてもらいたいです」

未経験を採る会社は、教育コストを先払いして
あとで回収する前提で動いてます。

だから「教わる気満々の人」より
「勝手に伸びそうな人」を採ります。
```

```
転職回数が多い人の、面接での説明の仕方。

1件ずつ言い訳すると苦しくなります。
全体を貫く軸を1本示すほうが通ります。

例：
「環境を変えて解決しようとしてきましたが、
根本は積み上がるスキルがないことだと気づきました。
だから今回は業界そのものを変えます」
```

## 伸ばすためのコツ

1. **リプライ営業をしない。リプライ支援をする**
   「未経験 IT 転職」で検索 → 悩んでる投稿に、売り込まず役立つ情報だけ置いてくる。
   プロフィールを見て、興味がある人だけが来ます。

2. **1投稿1メッセージ**
   詰め込むと読まれません。

3. **冒頭2行で決まる**
   タイムラインで見えるのは最初の2行だけ。ここに結論か引きを置く。

4. **数字を入れる**
   「3ヶ月」「1日1時間」「年収250〜320万円」など具体的なほど強い。

5. **週1でサイトの記事を増やす**
   `src/data/guides.ts` に追記すればページが増えます。
   投稿とリンクさせると回遊が生まれます。

---

## 絶対にやらないこと

- 実績の捏造（「支援実績100名」など、事実でない数字）
- 断定（「絶対転職できる」「必ず年収が上がる」）
- 他社・他サービスの誹謗
- DMでの一方的な売り込み
- 求職者への課金（職業安定法で原則禁止）
