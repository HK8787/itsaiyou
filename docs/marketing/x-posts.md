## 立ち位置について（重要）

運営者は **調理師として3年半働いたあと、未経験でIT業界に入って4年目**。
ヘルプデスク（うち約1年はリーダー）を経て、現在はSAPコンサルタントです。
資格は応用情報技術者・基本情報技術者・ITパスポート・G検定・Google広告認定・調理師。
詳細と、言えること／言えないことの線引きは `README.md` の2章にあります。

**これは当事者です。** 「未経験からIT」を体験談として書けます。

以下の投稿は**すべて事実の範囲内**で、そのまま投稿できます。空欄はありません。

投稿を足すときの線引きだけ覚えてください。

- **ヘルプデスク・インフラ・資格の話は、自分の経験として書いてよい**
- **開発（コードを書く仕事）の話は、調べた事実として書く**

「未経験からITエンジニアになって◯年目」のような、開発側の当事者は騙らないこと。
その必要もありません。ヘルプデスクは未経験者が最初に入る職種そのもので、
**そこのリーダーだった**という事実のほうが、この読者層にはよほど効きます。

## プロフィール（自己紹介欄・160文字）

Xの自己紹介は、相談していい相手かどうかを判断される場所です。
**何者か**と**何をしてくれるか**が、一行目で分かる必要があります。

**採用案**

```
調理師3年半→未経験でIT、今4年目｜ヘルプデスク（リーダー）→SAPコンサル｜「自分にITなんて無縁」と思ってる人向けに書いてます｜高卒・専門卒・フリーター歓迎／相談は何度でも無料、しつこい連絡はしません｜職種の違い・手取り・面接の答え方はサイトに
```

入れている要素は4つ。これ以上は詰め込まない。

1. **どこから来たか（調理師3年半→IT）** ← ここが最大の武器
2. 今どこにいるか（ヘルプデスク→SAPコンサル）
3. 誰向けか（「自分にITなんて無縁」と思っている人）
4. 押し売りされないか（無料・しつこい連絡はしません）

**1を先頭に置く理由**：Xでは肩書きのないアカウントは読まれませんが、
IT肩書きだけだと今度はフォロワーが「同業のエンジニア」になります。
集めたいのは異業種で迷っている人なので、**入口を調理師にします。**

「調理師3年半→未経験でIT、今4年目」は、それ自体がこのアカウントの主張です。
何も説明しなくても「その転職、実際どうでしたか」と聞きたくなる形にしてあります。

### 資格をプロフィールに入れていない理由

保有資格は応用情報技術者・基本情報技術者・ITパスポート・G検定・Google広告認定・調理師。
**それでも、Xのプロフィールには1つも入れていません。**

- 読み手（異業種・未経験）は、応用情報が何かを知りません。刺さりません
- 分かる人から見ても「ちゃんとやっている人」止まりで、差別化になりません
- 何より、**資格を頭に置いた瞬間に「向こう側の人」になります。**
  調理師→ITを入口にした意味が消えます

資格は、聞かれたときに答えれば十分な情報です。
サイトの `/about` と知恵袋の自己紹介には全部載せてあるので、
興味を持った人はそこで確認できます。

投稿の中で「応用情報を取ったときの勉強法」のように**中身として使う**のは有効です。
肩書きとして掲げるのと、経験として書くのは別物です。

**短縮案**（字数が超える場合）

```
IT未経験からの転職、一緒に考えます。
高卒・専門卒・フリーター歓迎／学歴不問の求人が中心
相談は無料、しつこい連絡はしません
```

> Xは日本語を2文字として数えることがある。貼って赤字になったら短縮案にする。

- 言い切る。「〜かもしれません」を消す

## リプライ営業（初期はこれが効きます）

フォロワーが増えるまでは、投稿より**リプライのほうが読まれます。**

Xの検索で次のワードを追って、悩んでいる投稿に答えてください。

- `未経験 IT 転職`
- `高卒 転職 不安`
- `IT 転職 学歴`
- `インフラエンジニア 未経験`
- `プログラミングスクール 迷ってる`

**リプライのルール**

- 宣伝しない。質問に答えるだけ
- URLを貼らない。興味を持った人はプロフィールを見に来ます
- 短く。3行以内
- 相手の状況を否定しない

例：

> 学歴で止まってるなら、未経験枠だけ見てみるといいですよ。
> こっちは学歴不問が多いです。母集団が違います。

> インフラなら入社初日から経験年数カウントされるので、
> 学習期間を挟むルートより先に進めます。急いでるならこっち。

これを1日5件、2週間。プロフィールへの流入が生まれます。

## 続けるための現実的な設計

- 1日1投稿。無理なら3日に1回でいい
- このファイルに約25本あるので、**1ヶ月弱は在庫があります**
- 在庫が切れたら、サイトの記事から同じ要領で切り出す
- 反応が良かった投稿は、1〜2ヶ月後に言い回しを変えて再投稿してよい

**やってはいけないこと**

- 実績や経歴を盛る（必ず崩れます）
- 「絶対受かる」「確実に年収が上がる」と書く（景品表示法の問題になります）
- 他社やスクールを名指しで批判する
